Base64, URL, Hex, HTML entities, Gzip, AES, RSA, JWT, hashing — all in one place

🔒 100% client-side — nothing you type here is ever sent to a server

Text Encoding

Reversible, no key needed. Works on any text; binary-looking output that isn't valid UTF-8 text will say so instead of showing garbage.

Gzip Compression

Compress text to Gzip bytes (shown as Base64 so it's copy-pasteable), or decompress a Base64 Gzip blob back to text.

Symmetric Encryption — AES-GCM

A passphrase derives a 256-bit key (PBKDF2, 100,000 iterations). Each encryption uses a fresh random salt + IV, packed together with the ciphertext into one Base64 blob — paste that whole blob back in with the same passphrase to decrypt. Same passphrase in and out.

Generate an RSA Key Pair

2048-bit RSA-OAEP (SHA-256). Generated entirely in your browser — the private key is never transmitted anywhere.

Encrypt

Encrypts with a Public Key. RSA can only encrypt small payloads directly — with a 2048-bit key that's roughly 190 bytes max. For larger data, encrypt it with AES instead and use RSA just to protect the AES passphrase.

Decrypt

Decrypts with a Private Key.

Encode (Sign)

Decode (Verify)

Header and payload are always decoded and shown, even without a key. Signature verification is optional — supply a secret/public key to check it.

Hash

One-way — there is no "decode" for a hash. Useful for checksums / integrity checks, not for secrets (use AES/RSA for anything that needs to come back).
