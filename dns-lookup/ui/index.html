DNS Lookup

Live DNS records for any domain — with a plain-language explanation of what each one means and why it matters

Look Up a Domain

Enter a domain (e.g. example.com) — pasting a full URL works too, the path/protocol is stripped automatically. Checks all 14 record types a domain could realistically have (A, AAAA, CNAME, MX, TXT, NS, SOA, CAA, SRV, NAPTR, DNSKEY, DS, TLSA, SSHFP) — most domains will show "no records found" for several of these, which is normal, not an error.

Lookups are sent directly from your browser to the chosen provider's public DNS-over-HTTPS API — nothing passes through this server.

Reverse Lookup — IP → Hostname ?

Enter an IPv4 address to find what hostname (if any) it's registered to point back to. Works for public IPs only — private ranges (like 192.168.x.x) aren't delegated in public DNS and will correctly show no result.
