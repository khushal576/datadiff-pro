Packet Journey

One real request, traced layer by layer — what gets added, what it's called, and what it actually looks like

The scenario: a browser sending GET /index.html HTTP/1.1 to example.com over plain HTTP/TCP/IPv4/Ethernet. We start at Physical (raw bits) and reveal one more header at each step — exactly what a receiving device actually does — until the plain HTTP request is fully exposed at the end.
